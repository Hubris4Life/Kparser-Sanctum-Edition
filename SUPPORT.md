# Support

## Before requesting help

Please confirm:

- You are using the newest Sanctum Edition release.
- KParser and XiLoader/FFXI are running at the same Windows privilege level.
- A character is fully logged in before memory detection is attempted.
- The problem still occurs after starting a fresh parse.
- Your report does not include private server credentials or an unsanitized parse database.

## Useful diagnostic information

- Sanctum Edition version and installation type
- Windows version
- XiLoader and FFXI process names shown in Task Manager
- Whether automatic memory detection succeeded
- Exact steps that reproduce the problem
- A screenshot with player and linkshell information removed when necessary
- Relevant parser messages copied as text

General usage questions and reproducible bugs may be filed through GitHub Issues. Security-sensitive reports must follow [SECURITY.md](SECURITY.md).
