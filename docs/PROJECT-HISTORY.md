# Project history

## Original project

KParser was created by David Smith as a combat parser for Final Fantasy XI and was developed during 2007-2009. Its original copyright notice licensed the program under GPL version 2 or any later version and identified its source location as Google Code.

Historical location:

    http://code.google.com/p/kparser/

## GitHub exports and maintenance forks

The Google Code history was exported to GitHub. The Sanctum source lineage passes through:

1. https://github.com/Kinematics/kparser
2. https://github.com/poroburu/kparser
3. The poroburu HorizonXI-Hotfix tag at commit a3dc8d095b3d3bc888fcea0b4e0a881ed5a08751

The maintenance fork adapted process names and memory offsets for classic-era private-server clients. Sanctum Edition preserves that history and does not claim authorship of the inherited parser.

## Sanctum Edition

In 2026, Sanctum Edition added automatic chat-memory discovery for the Sanctum environment and integrated it directly into KParser. The original Windows Forms engine was then given a bounded local report bridge and paired with a new .NET 10 WPF interface.

The new interface and reports are substantial additions, but the distributed product still contains and depends on modified KParser code. The complete project is therefore presented as a modified GPL-licensed derivative rather than merely an application inspired by KParser.

## Naming

KParser - Sanctum Edition distinguishes this version from upstream KParser. The name does not imply that David Smith, Kinematics, poroburu, EdenXI, HorizonXI, or Square Enix endorses or supports this project.
